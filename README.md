# GOORAK Cafe • Gallery — 3D Interactive Website

## How to deploy on GitHub Pages right now:
1. Create a new repository on GitHub (e.g., `goorak-cafe`).
2. Upload `index.html`, `style.css`, and `app.js` to the root of the repository.
3. Go to **Settings → Pages → Source**, choose `main` branch and `/ (root)`, then click **Save**.
4. Your live link (`https://<your-username>.github.io/goorak-cafe/`) will be ready in ~1 minute to generate a table QR code!

## Easy Customization Before Final Launch:
- **WhatsApp Number:** Open `app.js` and replace `CAFE_WHATSAPP = "989120000000"` with the cafe's real WhatsApp number.
- **Google Maps Link:** Open `index.html`, search for `google-maps-direct` and `gmap-iframe`, and paste the exact Google Maps link & embed code.
- **Menu Items & Prices:** Edit the `menuCatalog` array at the top of `app.js`.
